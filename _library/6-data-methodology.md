# 数据方法论图谱

> 数据是模型的燃料。但很多时候，需要的数据不存在、不够多、或者质量不够好。
> 这个库追踪的是**关于数据本身的方法论**——怎么造数据、怎么找数据、怎么筛选数据、怎么用已有数据榨出更多价值。
>
> **它与机制库的区别**：机制库收的是"算法层面的积木"（怎么训练、怎么推理），这个库收的是"数据层面的积木"（数据从哪里来、怎么处理）。

## 1. 🤖 LLM辅助数据标注（LLM-assisted Data Annotation）

**本质**：用大语言模型自动处理文本数据，生成结构化 / 分解式标注，替代人工标注。

**能解决什么问题**：原始数据的文本描述通常是完整的、未分解的，但训练分解式模型需要概念级别的文本对。人工标注太贵，LLM 可以批量处理。

**代价 / 风险**：
- LLM 会引入系统性偏差
- 需要人工抽检
- 长尾概念容易标错

## 维护规则

1. **只收"方法"，不收"数据集"。** 数据集放笔记里，方法放这里。
2. **必须写代价。** 数据方法没有免费的，写清标注成本 / 偏差 / 规模上限。
3. **有条件才更新。** 论文没有数据方法创新就不要硬写。
