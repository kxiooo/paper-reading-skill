# 算子速查手册（Operator Cookbook）

> **这不是论文库，是"怎么把机制接进模型"的实现手册。**
> 算子 = 可复用的模块级操作（cross-attention / FiLM / mask / CFG / projection…）。
> 它是**稳定知识**，几乎不变——只在发现新算子时追加，不随论文更新。

## 📋 算子速查

| 算子 | 公式/本质 | 适合场景 | 接入位置 |
|------|-----------|---------|---------|
| concat 拼接 | `[x, y]` | 不做对齐假设、维度预算足 | 输入层 / 特征层 |
| add 加法（残差/对齐） | `x + F(x)` 或 `x + y` | 增量修正 / 平行信息 | 任意残差位置 |
| cross-attention | `softmax(QK^T)V` | 从另一模态按相关性提取 | 生成器各层 |
| self-attention | `softmax(QK^T)V`（同源） | 建模内部长程关系 | 生成器各层 |
| FiLM / 通道调制 | `γ⊙x + β` | 通道级条件控制 | 归一化层前 |
| adapter / LoRA | `x + σ(W_a x)` | 轻量微调、不改骨干 | 冻结主干旁路 |
| ControlNet 门控残差 | `x + tanh(γ)·branch(x, c)` | 强条件注入不破坏预训练 | 每层残差 |
| gated fusion | `g⊙x + (1-g)⊙y` | 两源软平衡 | 融合点 |
| CFG | `ε = ε_u + w(ε_c - ε_u)` | 可控生成强度 | 采样时 |
| score composition | `ε = Σ ε_θ(z_t, c_k, t)` | 多概念可加组合 | 去噪输出层 |
| mask / masked op | `m⊙x + (1-m)⊙y` | 局部控制 / 区域保持 | 任意层 |
| attention map 干预 | 直接修改注意力矩阵值 | 免训练语义控制 | attention 层 |
| 注意力图掩码监督 | `L = Σ(1 − dice(Â, M))` | 训练期把 grounding 蒸进权重 | 训练损失项 |
| 子空间投影 | `x = Proj_U(x) + Proj_{U⊥}(x)` | 解耦 / 零空间控制 | 速度/梯度空间 |
| 能量梯度引导 | `x ← x - η∇_x E(x)` | 约束/后验推断 | 采样迭代内 |
| 检索增强 | 查表选最近邻 | 初始化/参考注入 | 生成前 |
| 输入侧优化 | 优化 z_T / prompt / 条件嵌入 | 冻结模型个性化 | 生成前/采样中 |
| 量化（VQ/FSQ） | `argmin‖z-c‖` / `⌊L/2·tanh⌉` | 连续→离散符号层 | 编码层 |
| 闭环反馈（PID） | `u += Kp·e + Ki·Σe + Kd·Δe` | 参考一致追踪 | 生成外部 |

## 怎么用

1. 先在 `[[2-mechanism-atlas]]` 确定机制（例如"约束引导"）
2. 来这里找对应算子（例如 energy guidance / projection / masked op）
3. 对照"接入位置"和"适合场景"选实现
4. 去代表论文里看真实代码 / 超参

## 新增算子的标准

只有满足以下全部条件才新增一行：

- [ ] 可以在多个任务中复用，不是某篇论文的专属 trick
- [ ] 有清晰的输入 / 输出和接入位置
- [ ] 能用一句话或一个公式说清本质
- [ ] 与表里已有算子不是同义重复（否则合并）

## 维护规则

- 这张表**只增不删**。过时的算子标记 `（不推荐）`，保留历史。
- 不写论文名，只写算子。论文归属放在机制图谱节点里。
- 公式用 LaTeX，保持可复制。
